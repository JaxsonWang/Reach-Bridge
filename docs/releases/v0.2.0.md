# Reach-Bridge v0.2.0

## 新增

- 内置中文 WebUI：渠道开关、动作与域名策略、API 凭据、Cookie 导入、专用浏览器登录、只读操作台和异步任务状态。
- 支持 Agent-Reach 1.6.1 全部 14 个渠道的已授权只读动作，包括字幕、转录、评论读取、热门、用户资料与行情。
- 独立管理员令牌、短期 HttpOnly 会话、Origin / CSRF 校验；管理默认关闭，默认要求 HTTPS，私网 HTTP 需要显式选择。
- 浏览器登录采用受管理会话保护的截图与输入转发，不公开 CDP / VNC；镜像提供 Chromium sandbox、Node、Xvfb、ffmpeg 与中文字体。
- 管理操作与查询互斥；Cookie / Token 通过 stdin 进入固定管理程序，不在命令参数中传递，也不提供已保存凭据导出。

## 升级

镜像：`ghcr.io/jaxsonwang/reach-bridge:0.2.0-agent-reach-1.6.1`，支持 `linux/amd64`、`linux/arm64`。同时提供源码、Python 包及分架构离线镜像。

保留 `.env`、`config/` 和整个 `data/home`。旧查询接口与查询令牌继续使用，不要求启用管理。新增管理配置见 README / `.env.example`；管理员令牌必须与查询令牌不同。

第一次启用管理会以原 `config/channels.json` 创建 HOME 下 `.reach-bridge/channels.json`，之后控制台以该可写文件为唯一策略来源，保存即生效。

管理适配器支持固定上游 1.6.1，升级其他上游版本前需适配。平台能力仍取决于上游实现、依赖、出站网络、登录与网站限制，保存会话后请通过实际动作验证。
