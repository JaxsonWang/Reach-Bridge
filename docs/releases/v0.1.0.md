# Reach-Bridge v0.1.0

为受限终端环境提供 Agent-Reach 的只读平台搜索与内容读取接口。

## 功能

- Bearer 令牌认证，提供平台列表、搜索、明确 URL 读取和受保护的 OpenAPI 定义。
- 平台与精确 HTTPS 域名允许列表，不开放任意 Shell、安装、登录或升级 API。
- 有界并发、排队与执行时限、请求与输出大小限制，以及断开后的请求进程组回收。
- 保留上游结果的实际渠道、后端、来源与错误，不把失败包装为成功。
- 固定 Agent-Reach **1.6.1**，提供正式 release 检查、显式升级、完整 HOME 快照与配套回滚。

## Docker 部署

镜像支持 **linux/amd64** 与 **linux/arm64**，使用同一多架构地址：

```sh
docker pull ghcr.io/jaxsonwang/reach-bridge:0.1.0-agent-reach-1.6.1
```

下载 `Reach-Bridge-0.1.0.zip`，解压后按 README 配置 `.env` 并使用 Compose 部署。常规部署直接拉取镜像；只有显式源码构建或切换上游版本时才使用 `compose.build.yaml`。

离线环境可下载对应架构的镜像归档并用 `docker load -i <文件>` 导入；不要导入其他架构的归档。

## 发布文件

- `Reach-Bridge-0.1.0.zip`：完整源码、Compose 配置、维护脚本与文档。
- `reach_bridge-0.1.0-py3-none-any.whl` / `reach_bridge-0.1.0.tar.gz`：Python 包与源码分发包。
- `reach-bridge_0.1.0-agent-reach-1.6.1_linux-amd64.tar.gz`：amd64 离线镜像。
- `reach-bridge_0.1.0-agent-reach-1.6.1_linux-arm64.tar.gz`：arm64 离线镜像。

需要浏览器登录的平台仍依赖适配的浏览器与图形登录环境。容器就绪验证 CLI 与接口契约，不代表每个平台已完成登录或实际查询验证。
