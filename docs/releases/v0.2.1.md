# Reach-Bridge v0.2.1

在 v0.2.0 完整 WebUI 与浏览器支持基础上，新增可显式选择的无浏览器运行模式，供受限内核环境使用。

- `REACH_BRIDGE_BROWSER_ENABLED=false`：只执行明确的原生动作，不启动或准备浏览器；已有策略与凭据保留。
- 新增官方登录页／凭据页入口与本机 F12 Cookie 获取指导；不会跨站读取 Cookie。
- 保留 API Key / Token、哔哩哔哩及 YouTube 原生 Cookie 导入、原生渠道依赖安装与只读操作台。
- 浏览器查询、网页登录、浏览器 Cookie 导入和会准备浏览器的渠道安装明确返回 `BROWSER_DISABLED`；不自动降级、不关闭 sandbox。
- 雪球保留 `quote` / `search`；验证仅执行原生搜索，不触发社区路径。
- 操作台显示每个动作的浏览器依赖，原生模式不把浏览器动作显示为可执行。

默认浏览器模式不变：在支持用户命名空间的主机上，以非 root 用户和随包 seccomp 配置运行。真实浏览器、扩展、1280×800 登录画面、点击、文字、按键、滚动及刷新已在 amd64 / arm64 原生 CI 验证。

镜像：`ghcr.io/jaxsonwang/reach-bridge:0.2.1-agent-reach-1.6.1`。

升级保留 `.env`、只读配置与整个 `data/home`。完整配置与运行边界见 README；Cookie 保存后仍需通过实际动作验证平台访问。
