在本机浏览器获取 Cookie
  1. 打开官方页面，由你本人登录；B 站可使用 App 扫码。
  2. 按 F12（Mac 可按 ⌥⌘I），在 Network 刷新页面，选择发往本站的请求。
  3. 复制 Request Headers 中 Cookie 的值，回到这里粘贴。也可在 Application → Cookies 查看，或导出本站 Cookie JSON 数组。

document.cookie 会漏掉 HttpOnly Cookie。不要上传 HAR、整段 cURL 或其他站点的 Cookie，也不要把凭据发到聊天里。
